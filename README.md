# dotfiles

My linux configurations setup for daily driving

### Prerequisites

- git, i3, alacritty chezmoi, hyprland, kitty, wofi, waybar

- neovim, fd-find, ripgrep, tree-sitter-cli, Iosevka Nerd Font

### Setup

```bash
sudo pacman -S chezmoi

chezmoi init --apply https://github.com/maevik/dotfiles.git
```

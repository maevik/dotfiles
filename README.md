# dotfiles

My linux configurations setup for daily driving

### Prerequisites

- git
- chezmoi
- neovim
- fd-find
- ripgrep
- tree-sitter-cli
- Iosevka Nerd Font


- i3
- alacritty

or

- hyprland
- kitty
- wofi
- waybar

### Setup

```bash
sudo pacman -S chezmoi

chezmoi init --apply https://github.com/maevik/dotfiles.git
```
